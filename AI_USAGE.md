# AI usage

I'm the author of this project and responsible for everything in it. For
transparency, this file records where I used an AI assistant.

**Assistant:** Claude (Anthropic), model Claude Opus 5.5, used through Claude Code.

## How I used it

I set the project's goals and scope and decided on the components and security
requirements: signed results, reconciliation, a tamper-evident audit log, a public
dashboard, monitoring, and fictional data only. Claude then drafted the
implementation, tests and documentation from that brief. I review, run and test
everything before committing, and I will keep this file updated as the project changes.
